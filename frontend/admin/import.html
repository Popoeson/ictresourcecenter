Before you upload

  1. Set up institutions, departments and levels in Structure first.
  2. Names in the file must match them exactly (case and extra spaces are ignored).
  3. Columns: Surname, Firstname, Othername, Department, Phone, Email, Institution, Level.
  4. Each row needs an email or a phone number. Rows already in the list are skipped.

Excel (.xlsx) or CSV. Up to 5 MB and 5,000 rows.
